# Flecs Bindings For Odin
Flecs ECS bindings for odin made using odin-c-bindgen by karl-zylinski

just drop it in it works :D

beware that it's experimental, I'm in no way an expert. But so far i haven't found anything that's broken. 

also some types are different so read the description or the binding file "flecs.odin",
like they expect values in a certain way at times because of translation errors. but they all work. just read the flecs.odin file for reference if ever get stuck, plus just hover over the function it'll give general information about what the function expects.. hopefully :D
